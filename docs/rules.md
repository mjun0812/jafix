# ルール一覧

組み込みのルールは102個です。
使うルールは、[設定ファイル](./configuration.md#rules)の `[builtin]` でルールIDかpreset名を指定して選べます。

| 列       | 意味                                                                                                                   |
| -------- | ---------------------------------------------------------------------------------------------------------------------- |
| 種類     | 「修正」は本文を書き換え、「指摘」は報告する。「修正と指摘」は両方に対応する。`jafix check` は修正できる箇所も出力する |
| 初期状態 | 「有効」は既定の10ルール。「-」のルールは設定で有効にできる                                                            |

各ルールのオプションと既定値は、[リファレンス](https://github.com/mjun0812/jafix/blob/main/REFERENCE.md#組み込みのルール)で確認できます。

## jafix独自の修正 {#jafix}

| ルールID                     | 種類 | 初期状態 | 内容                                         |
| ---------------------------- | ---- | -------- | -------------------------------------------- |
| `fullwidth-paren`            | 修正 | 有効     | 全角括弧を半角にする                         |
| `space-between-ja-and-alnum` | 修正 | 有効     | 日本語の文字と半角英数字の間の空白を削除する |
| `space-between-ja-and-paren` | 修正 | 有効     | 日本語の文字と括弧の間の空白を削除する       |

## 日本語標準スタイルガイド {#jtf-style}

日本翻訳連盟(Japan Translation Federation、JTF)の[JTF日本語標準スタイルガイド(翻訳用)](https://www.jtf.jp/tips/styleguide)は、翻訳文の日本語表記をそろえるための指針です。

jafixには、このガイドに基づく37ルールがあります。そのうち33ルールは `preset-jtf-style = true` で有効になります。
残る `2.1.2.漢字`、`2.1.5.カタカナ`、`2.1.6.カタカナの長音`、`2.2.1.ひらがなと漢字の使い分け` は個別に指定します。
JTFのルールIDをTOMLのキーに書くときは、引用符で囲みます。

JTFの `4.3.1.丸かっこ（）` は和文で全角括弧を求めます。jafixの既定ルール `fullwidth-paren` は全角括弧を半角に直します。
presetを使うときは、使いたい括弧の表記に合わせて片方を無効にします。
次の設定では、和文の丸括弧を全角で書きます。

```toml
[builtin]
preset-jtf-style = true
fullwidth-paren = false
```

## 英語の綴りと表現 {#english}

よくある誤綴りに絞るには、`common-misspellings` だけを有効にします。
すでに `spelling` を使っている場合は、`spelling = false` で無効にします。

`spelling` で辞書を使って綴りを調べる場合は、プロジェクトで使う固有名詞や技術用語を `skipPatterns` に指定できます。

| ルールID              | 種類       | 初期状態 | 内容                                                                                                                      |
| --------------------- | ---------- | -------- | ------------------------------------------------------------------------------------------------------------------------- |
| `terminology`         | 修正と指摘 | -        | 技術用語、ブランド、略語の表記を確認する。利用者が `terms` に書いた置き換えは修正し、組み込みの辞書に基づく箇所は指摘する |
| `spelling`            | 指摘       | -        | 米国英語のHunspell辞書にない語を指摘する。設定に従って修正候補を出す                                                      |
| `common-misspellings` | 指摘       | -        | 一覧にある誤綴りと正しい表記を示す                                                                                        |
| `write-good`          | 指摘       | -        | 曖昧な語、受け身、冗長な句などを指摘する                                                                                  |
