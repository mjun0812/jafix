# textlint由来のルール

## 使うルールを選ぶ {#configuration}

組み込みのルールは `~/.config/jafix/config.toml` の `[builtin]` で選べます。
`XDG_CONFIG_HOME` を設定している場合は、`$XDG_CONFIG_HOME/jafix/config.toml` を使います。

ルールのIDをキーにして、`true` で有効、`false` で無効にします。
オプションを指定する場合は、値を `{ max = 120 }` のようなTOMLの表にします。

次の例では文の長さの上限を120に設定し、感嘆符と疑問符の指摘を止めて、よくある英語の誤綴りを調べます。

```toml
[builtin]
sentence-length = { max = 120 }
no-exclamation-question-mark = false
common-misspellings = true
```

日本語の技術文書向けの23ルールは、初期状態で有効です。
ほかの組み込みルールはルールIDかpresetの名前を指定して有効にできます。
**preset**は複数のルールをまとめて設定するためのキーです。
同じルールにpresetと個別の設定がある場合、jafixは個別の設定を使います。

表の「修正」は `jafix fix` やhookで書き換える処理を、「指摘」は当たった箇所を報告する処理を表します。
`jafix check` はどちらの箇所も報告します。

## AIが多用する書き方 {#ai-writing}

`preset-ai-words-ja = true` で有効になるのは `no-ai-words` です。

| ルールID                    | 種類 | 内容                                                                           |

| `no-ai-list-formatting`     | 指摘 | リスト項目の先頭にある太字とコロンなどの組み合わせや、項目内の絵文字を指摘する |
| `no-ai-hype-expressions`    | 指摘 | `革命的な` など、一覧にある誇張表現を指摘する                                  |
| `no-ai-emphasis-patterns`   | 指摘 | 絵文字と太字の組み合わせや、見出し内の太字などを指摘する                       |
| `no-ai-colon-continuation`  | 指摘 | 述語とコロンで終わる段落に、コードブロックやリストなどを続ける書き方を指摘する |
| `ai-tech-writing-guideline` | 指摘 | 冗長な表現、受け身、具体性を欠く語、表記の揺れなどを指摘する                   |
| `no-ai-words`               | 指摘 | AIが多用する語を、品詞と原形に基づいて指摘する                                 |
| `no-short-topic-comma`      | 指摘 | 短い主題を示す「は」の直後の読点を指摘する                                     |

## JTFスタイルガイド {#jtf-style}

`preset-jtf-style` は37個のIDを持ち、そのうち4つは個別に有効にします。
該当するIDは `2.1.2.漢字`、`2.1.5.カタカナ`、`2.1.6.カタカナの長音`、`2.2.1.ひらがなと漢字の使い分け` です。
JTFのIDには句読点や空白を含むものがあるため、TOMLのキーは引用符で囲みます。

JTFの丸括弧のルールは全角を求めますが、jafixが初期状態で使う `fullwidth-paren` は全角の括弧を半角に直します。
presetを有効にするときは、使いたい括弧の表記に合わせて片方を無効にします。
次の例は和文の丸括弧を全角で書く場合の設定です。

```toml
[builtin]
preset-jtf-style = true
fullwidth-paren = false
```

| ルールID                             | 種類 | 内容                                                                           |

| `ja-hiragana-hojodoushi`             | 指摘 | 「お願い致します」の「致し」など、補助動詞を漢字で書いた箇所を指摘する         |
| `ja-hiragana-keishikimeishi`         | 指摘 | 「見た事がある」の「事」など、形式名詞を漢字で書いた箇所を指摘する             |
| `ja-keishikimeishi`                  | 指摘 | 形式名詞を漢字で書いた箇所を指摘する。「ほう」と「うえ」は設定で対象から外せる |
| `ja-hiragana-fukushi`                | 指摘 | 「既に」など、ひらがなで書く副詞を漢字で書いた箇所を指摘する                   |
| `ja-hiragana-daimeishi`              | 指摘 | 「何処」など、ひらがなで書く代名詞を漢字で書いた箇所を指摘する                 |

## 英語の綴りと表現 {#english}

よくある誤綴りに絞るには、`common-misspellings` だけを有効にします。
すでに `spelling` を使っている場合は、その設定を `false` に置き換えます。

`spelling` で辞書を使って綴りを調べる場合は、プロジェクトで使う固有名詞や技術用語を `skipPatterns` に指定できます。

| ルールID              | 種類       | 内容                                                                                                                      |
| --------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------- |
| `terminology`         | 修正と指摘 | 技術用語、ブランド、略語の表記を確認する。利用者が `terms` に書いた置き換えは修正し、組み込みの辞書に基づく箇所は指摘する |
| `spelling`            | 指摘       | 米国英語のHunspell辞書にない語を指摘する。設定に従って修正候補を出す                                                      |
| `common-misspellings` | 指摘       | 一覧にある誤綴りと正しい表記を示す                                                                                        |
| `write-good`          | 指摘       | 曖昧な語、受け身、冗長な句などを指摘する                                                                                  |

## 利用者の置き換えとfilter {#custom-rules-and-filters}

プロジェクト固有の表記や禁止語は、`[builtin]` に辞書やパターンを書いて指定できます。

| ルールID                 | 種類       | 内容                                                                |
| ------------------------ | ---------- | ------------------------------------------------------------------- |
| `prh`                    | 修正と指摘 | `rulePaths` に指定したprh辞書に従って、表記を置き換える             |
| `@textlint-rule/pattern` | 修正と指摘 | `patterns` の一致を、`replace` があれば置き換え、省略すれば指摘する |

`[filters]` の `comments` はHTMLコメントで指定した範囲を、`allowlist` はパターンに一致した範囲を修正や指摘の対象から外します。
