# jafix

jafix is a command-line tool for proofreading Japanese Markdown.
It standardizes details such as full-width parentheses and spacing, and reports findings that need review.
Choose which rules to use in your configuration file.

- Run `jafix check FILE.md` to see findings
- Run `jafix fix FILE.md` to write fixes to the file
- Browse the [rules from textlint](./textlint-rules.md)
- Read the [performance comparison with textlint](./benchmark-vs-textlint.md)

The [Japanese documentation](../index.md) is the source of truth.
